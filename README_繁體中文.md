# 台股 AI 紙上交易研究系統

## 部署
此專案已部署於 Streamlit Community Cloud。GitHub main 分支更新後，Streamlit 會自動重新部署。

## 目前功能
- 10 檔上市台股觀察清單，可選 1、2、3、5 年日線資料。
- EMA21/50/200、RSI14、MACD、OBV、ATR、20/60 日報酬及量價突破條件。
- 隨機森林初步模型：以歷史技術特徵預測未來 5 個交易日報酬是否超過 1.5%，按時間順序切分訓練/測試，顯示測試平衡準確率。
- 三大法人最新可取得交易日資料（TWSE T86），作為觀察欄位及規則評分加分條件。
- Yahoo Finance 1 分鐘盤中參考價（可能延遲，非交易所認證即時行情）。
- 簡化歷史回測、估算交易成本、CSV 匯出。
- 純模擬帳本：模擬買進/賣出、現金、持倉與成交紀錄；僅保存在目前 Streamlit 工作階段。

## 重要限制
- 歷史日線來自 Yahoo Finance 自動調整資料，逐檔可用期間可能不同。
- 盤中參考價可能延遲、缺漏或中斷，不能視為可成交報價。
- 三大法人資料只抓最近可取得交易日，尚未建立多年法人歷史序列；若官方 API 不可用，欄位留空，不以猜測補值。
- 尚未接入融資融券、借券、分點進出與完整財報因子。
- 隨機森林為研究原型，不是已證實有效的預測系統；模型機率與歷史測試分數均不代表未來勝率或獲利保證。
- 回測尚未完整處理除權息現金流、停牌、漲跌停排隊、流動性、下市股偏誤與 walk-forward 多區段驗證。
- 模擬帳本只存在目前工作階段，Streamlit 服務重啟或工作階段結束時可能清空，尚未提供跨裝置永久保存。
- 不連接券商、不會送出真實委託、不使用真實資金。

## 回測成本假設
- 手續費：0.1425%（未套用個別券商折扣）
- 一般股票賣出證交稅：0.3%
- 滑價：每次成交估算 0.1%
