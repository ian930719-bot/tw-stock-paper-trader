# 台積電 2330｜歷史買賣點與交易邏輯拆解（截至 2026-11-11）

## 研究範圍與結論

本文件只研究台積電 2330，不延伸到其他股票。目標是找出可在當時資訊下執行的低點買進、高點賣出邏輯，而不是把事後最低價、最高價冒充可交易訊號。

本次使用既有 Run #32 的逐日特徵、凍結訊號規則、逐筆成交帳與 2010–2026-11-09 價格資料；另以證交所 2026-11-10、11-11 日行情更新現況。回測期間 2016-01-04 至 2026-11-09，下一交易日開盤成交，成本含買賣手續費、賣出證交稅及雙邊 0.1% 滑價。

**結果：目前最佳可重現的凍結訊號組合年化 28.46%，最大回撤 -45.64%，未能證明它是全歷史全域最佳，更未達到 200% 年化。** 這是可交易訊號的歷史結果，不是事後完美低買高賣的理論上限。

## 我目前採用的買進邏輯：恐慌賣壓衰竭

在已完成的 500 個轉折事件/對照樣本中，LOW 前一交易日相對於同年、同趨勢狀態的對照日，常見特徵包括：
- 1 日、3 日、5 日報酬較弱；
- RSI/Stochastic 較低；
- 收盤位置偏向當日區間下緣；
- OBV 短期資金流較弱；
- 但成交量相對 20 日均量放大，顯示賣壓集中釋放。

凍結 LOW 訊號要求同時成立：
1. 相對 20 日均量 >= 1.2；
2. 當日報酬 <= -1%；
3. Stochastic K <= 30；
4. 收盤位置 <= 0.25；
5. OBV 5 日資金流比率 <= 0；
6. 不在公司行動資料遮罩期。

**為什麼買：** 不是因為股價跌了就抄底，而是要求「放量下跌 + 超賣 + 收在低位 + OBV 偏弱」同時出現。這組條件試圖辨識集中賣壓/恐慌出清。訊號在收盤後才成立，故只能下一交易日開盤買，不能回填到當日最低點。

## 我目前採用的賣出邏輯：高檔延伸但動能開始衰退

凍結 HIGH 訊號要求：
1. 當日報酬 >= +1%；
2. 收盤位置 >= 0.70；
3. 當日高低振幅 >= 1.6%；
4. 收盤高於 SMA200 至少 10%；
5. MACD histogram 3 日變化 <= 0；
6. SMA50 斜率仍為正；
7. 不在公司行動資料遮罩期。

**為什麼賣：** 單純大漲不是賣點。策略要求價格已遠離長期均線、當日波動擴大、短期動能轉弱，但中期趨勢仍向上。這是「趨勢過度延伸、上漲動能可能衰竭」的出場預警。訊號收盤後確認，下一交易日開盤賣出。

## 整體績效與我對邏輯的批判

- 初始資金：NT$100,000
- 期末資產：NT$1,512,473
- CAGR：28.46%
- 最大回撤：-45.64%
- 23 筆交易，勝率 86.96%，持倉曝險約 70.33%
- 同期買進持有：期末 NT$1,556,027，CAGR 28.79%，最大回撤 -45.68%。

這個訊號組合沒有打敗買進持有。它提高了交易勝率，但沒有提高長期複利報酬。

我認為自己的交易邏輯仍有四個缺陷：

1. **低點訊號其實偏向「恐慌後確認」，不是最低點預測。** 放量下跌且收在低位，可能是最後一波賣壓，也可能是下跌趨勢延續。缺少隔日/後續買盤承接確認，會造成接刀。
2. **高點訊號可能過度依賴延伸程度。** SMA200 距離 10% 是固定門檻，不能區分強勢趨勢中的正常擴張與真正的趨勢末端。
3. **全進全出讓訊號錯誤成本很高。** 一次假 LOW 會把大部分資金投入錯誤位置；若出場太慢，回撤會很深。
4. **高勝率不等於好策略。** 86.96% 勝率看似高，但最終 CAGR 仍略輸持有；真正的目標應是提高每單位回撤的複利效率，而非追求勝率。

因此下一個模型應優先測試：LOW 先預警、再用後續收盤站回前一日高點/短均線確認；HIGH 則同時要求「長期乖離 + 動能背離/轉弱 + 量價失衡」，並用波動率調整出場，而不是直接把單一門檻改到回測最漂亮。

**因此依照目前凍結規則，2026-11-11 不是新的 LOW 買點，也不是 HIGH 賣點。** 它比較像急跌後的反彈修復：價格重新站回 20 日線，但仍在 50 日、100 日線附近/下方。此時追買缺乏低點訊號；直接放空或賣出也沒有符合本策略的高點轉弱訊號。下一步應觀察能否有效站穩 50/100 日線，或回測 20 日線附近時出現縮量止跌、再放量轉強。這是條件式觀察，不是保證價位。

資料依據：TWSE 2026-11 月 2330 每日成交資訊；Run #32 歷史特徵與逐筆交易輸出。簡化 SMA/RSI 指標使用原始日線序列，未將完整股利現金流併入總報酬，因此現況技術數值與回測調整序列可能有細微差異。

## 研究決策

這是目前台積電可重現的交易邏輯與逐筆買賣位置。它是基準版本，不宣稱全域最佳。接下來應直接針對台積電研究更早的 LOW 確認與更及時的 HIGH 出場，並在未參與調參的時間段做驗證；不能再把同一段歷史反覆調到漂亮。
