# 台積電 2330 波段轉折標籤敏感度與事件 Bootstrap V5

## 目的
驗證 V4 的轉折前特徵是否依賴單一 10% ZigZag 定義，並以事件配對為單位估計中位數差異的 95% bootstrap 信賴區間。

## 資料與方法
- 4,101 個交易日，2010-01-04 至 2026-11-10。
- Yahoo Finance `auto_adjust=True` 調整後 OHLCV；不是證交所原始成交資料。
- 轉折幅度測試 6%、8%、10%、12%、15%；轉折點仍是未來價格確認的事後標籤。
- 控制組同年度、排除轉折前後 35 個交易日，按 MA60 乖離與 ATR% 配對，控制日期不重複使用。
- 以配對事件為單位、有放回抽樣 5,000 次，固定亂數種子 23302026，計算中位數配對差異的 percentile 95% CI。

## 解讀
1. **低點前5日的超跌特徵在 6%～12% 定義下方向一致**：RSI、布林位置與20日回撤多呈負向差異，且多數 bootstrap CI 不跨 0；但在 15% 定義下樣本縮至11組，RSI CI 已跨 0。這支持「接近低點時已明顯超跌」的描述，不代表能提前知道最低點。
2. **高點前1日 RSI 在所有測試幅度下皆高於控制組**，CI 均未跨 0；但這是非常接近轉折的事後特徵，仍不等於有足夠提前量的賣出訊號。
3. 10% 標籤下高點前1日 MA60乖離與40日報酬的 CI 為正，但在其他幅度下穩定性較弱，不應單獨升格為規則。
4. 事件數少、同一歷史價格路徑跨閾值重疊，bootstrap CI 僅反映配對事件抽樣不確定性；不能視為獨立市場制度的保證。

## 結論與下一步
目前較穩定的描述是「低點附近短期超跌」及「高點前極短期過熱」。兩者仍偏向辨識轉折附近狀態，尚未證明可形成有正期望值的提前交易策略。下一步應固定特徵與門檻，不再用同一測試期調參，改做按時間順序的 walk-forward 預警分數，並以訊號隔日開盤成交、計入成本及台股交易規則回測。只有通過未觸碰的 OOS 區間才可考慮納入策略。
